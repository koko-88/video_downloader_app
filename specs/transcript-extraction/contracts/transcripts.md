# Transcript interface and output
Transcripts tab: multiline URLs, folder, exact language, four precedence modes, independent MD/TXT/JSON/SRT/VTT, optional local-ASR checkbox. Actions Extract / Resume, Retry failed, Cancel, Open folder. Same inputs/choices resume batch. Show scan/extraction/export counts and per-video states.
Unsupported named-extractor input fails per input. Missing requested language = language_unavailable; truly no tracks = caption_absent. ASR unavailable never transcript success. Classified static errors omit secrets.
UTF-8 TXT cue text/newlines; MD escaped title/provenance and timestamped cues; JSON schema 1/provenance/millisecond cues; SRT numbered HH:MM:SS,mmm; VTT WEBVTT plus HH:MM:SS.mmm. Escape markup where rendered. Overlap/repeated cues preserved. Malformed input fails explicitly, no silent partial parse.
Atomic manifest. Outputs confined within batch. Never overwrite differing files; reuse interrupted files only byte-identical. Verify success hashes before skipping. Batch lock prevents concurrent writes.

Rate-limited discovery or extraction halts new requests for the run. The manifest records `halt_reason: rate_limited`, keeps unattempted items pending and completed outputs intact, and the UI displays Rate limited. Extract / Resume and Retry failed are explicit operator actions; no background automatic rate-limit retry is scheduled. Schema 1 manifests without halt_reason remain compatible.

Production details: TXT/JSON retain paragraph separators; SRT/VTT collapse blank paragraph lines within a cue to one line break because blank lines delimit timed cues. Request URLs with provider-specific identity parameters remain in worker memory and are rediscovered from the original inputs on restart; persisted provenance stays sanitized. Invalid manifest states, attempts, cross-references, output paths and hashes are rejected before mutation. Windows output publication uses exclusive rename and does not require filesystem hard links. UI tables update changed rows through Qt models; worker progress contains display deltas rather than repeated full manifests.
